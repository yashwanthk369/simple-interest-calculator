# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal is the initial amount.
- Rate is the annual interest rate in percentage.
- Time is the duration in years.

## How to Use

1. Open a terminal on a system with Bash and AWK installed.
2. Navigate to the directory containing `simple-interest.sh`.
3. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:

   ```bash
   ./simple-interest.sh
   ```

5. Enter the principal amount, annual interest rate, and time in years when prompted.

## Example

For a principal of 1000, an annual interest rate of 5%, and a duration of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
