
# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

We welcome contributions that improve the code, documentation, usability, and reliability of this project.

## How to Contribute

1. Fork this repository to your GitHub account.
2. Clone your fork to your local computer.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear commit message.
6. Push your branch to your fork.
7. Open a pull request describing your changes.

## Reporting Bugs

When reporting a bug, please include:

- A clear description of the problem.
- Steps to reproduce the issue.
- The expected result and the actual result.
- Relevant error messages, if any.

## Suggesting Improvements

Please explain the proposed improvement, why it would be useful, and how it could benefit users.

## Code Guidelines

- Keep the code simple and readable.
- Use meaningful variable names.
- Include comments where necessary.
- Validate user input.
- Test changes before submitting a pull request.

## Commit Messages

Use short, descriptive commit messages, such as:

- Add input validation
- Improve calculator documentation
- Fix interest calculation

## Pull Requests

- Explain the purpose of your changes.
- Keep each pull request focused on a specific improvement.
- Make sure your changes do not introduce known errors.
- Respond constructively to review feedback.

## Code of Conduct

All contributors are expected to follow the project's Code of Conduct.

Thank you for helping improve this project!
